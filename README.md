# Role Identifier

**Role Identifier** is an **ArcheAge** addon that identifies a player's role (Tank/Healer), main skillset, and gear score, displaying appropriate icons next to the target's name.

## 📌 Features

- Automatically detects the class and role of the selected player.
- Displays an icon corresponding to the role (Tank/Healer).
- Identifies the main skillset.
- Shows the target's gear score.
- Flexible settings for positioning icons and text.

## ⚙ Settings

- Enable/disable class name and gear score display.
- Choose icon type (role-based, gear-based, or skillset-based).
- Adjust icon and text size.
- Modify UI element offsets.
